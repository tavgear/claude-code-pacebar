# claude-code-pacebar

Строка статуса для Claude Code: показывает, с какой скоростью расходуются лимиты
и укладываешься ли ты в дневную долю недельного бюджета.

```
Opus 5 · xhigh   5ч:[▓▓▓▓▓46%     ] 3ч   день:[▓▓▓▓▓64%▓    ]   нед:[▓▓▓▓52%      ] 4д   ctx:[▓▓▓33%       ]
```

Слева направо: модель и уровень усилий, четыре плашки — окно 5 часов, дневная
доля недели, неделя целиком, заполнение контекста. Рядом с плашками окон —
время до сброса. Цвет заливки по тяжести: <50% зелёный, 50–79% жёлтый, 80%+ красный.

## Плашка «день» — суть проекта

Claude Code отдаёт только два окна: 5 часов и 7 суток. Недельный процент сам по
себе бесполезен: 50% в понедельник — беда, 50% в пятницу — запас. Плашка «день»
переводит недельный расход в понятный вопрос «как я иду сегодня»:

- неделя делится на 7 равных суток по 100/7 % каждые;
- сутки отсчитываются от старта недельного окна (`resets_at − 7д`), не от полуночи;
- показывается процент **сегодняшней** нормы: 100% — норма выбрана, больше —
  залез в завтрашний день, `+N%` на пустой плашке — запас со вчера.

Ничего, кроме приходящих от Claude Code данных, для этого не нужно: ни истории,
ни состояния на диске.

## Установка

Нужны `bash`, `jq`, `awk`, GNU `date` и терминал с 256 цветами.

```bash
git clone <repo> ~/ai/claude-code-pacebar
ln -s ~/ai/claude-code-pacebar/statusline.sh ~/.claude/statusline.sh
```

В `~/.claude/settings.json`:

```json
"statusLine": { "type": "command", "command": "~/.claude/statusline.sh" }
```

## Как посмотреть, не дожидаясь лимитов

```bash
./preview.sh          # галерея типовых состояний
./preview.sh 42 55 30 # своё: 5ч%, неделя%, контекст%
```

## Широко и узко

Ширину терминала Claude Code кладёт в `COLUMNS`. От 125 колонок — развёрнутый вид
(подписи, знаки процента, «4д 14ч»), уже — компактный: одна буква модели,
плашки без подписей, время как `4:14`, плашка дня скрыта.

## Вход

Скрипт читает со stdin JSON от Claude Code и берёт из него:

| поле | назначение |
|---|---|
| `.model.display_name` | имя модели |
| `.effort.level` | уровень усилий |
| `.rate_limits.five_hour.used_percentage` / `.resets_at` | окно 5 часов |
| `.rate_limits.seven_day.used_percentage` / `.resets_at` | недельное окно |
| `.context_window.used_percentage` | заполнение контекста |

Чего нет во входе — та плашка просто не рисуется.
